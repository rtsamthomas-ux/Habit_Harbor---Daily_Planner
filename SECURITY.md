# Security policy

## Supported version

The current default branch is the supported version.

## Reporting a concern

Please do not post sensitive details in a public issue. Use GitHub's **Report a vulnerability** option for this repository if it is available. Otherwise, contact the repository owner privately through GitHub and include the affected file or feature, the impact, and steps to reproduce it.

## Data handling

Habit Harbor stores planner content in browser local storage on the device where it is used. The app does not include a server-side account or sync service. Do not commit exported planner backups, credentials, tokens, or other private data to the repository.
